The Social Simulation Audit Card

A five-step workflow for auditing robustness and calibrating scientific claims in LLM social simulations.

1

State the claim

  • Specify the scientific conclusion.
  • Define what must be preserved.
OutputMeasurable claim-preservation criterion.
2

Map perturbations

  • Classify with TRAILS-R or TRAILS-D.
  • Judge context relevance.
Interpretation rule
Relevant→ scope condition Irrelevant→ implementation dependence
3

Register and run

  • Set baseline and alternatives.
  • Fix models, seeds, and controls.
OutputPre-registered audit setup.
4

Analyze sensitivity

  • Estimate effects and uncertainty.
  • Check consistency across runs.
OutputMagnitude, precision, and consistency.
5

Scope the claim

  • Apply the preservation criterion.
  • Report the supported scope.
Outcomes
Robust Scope-limited Implementation-sensitive Inconclusive
